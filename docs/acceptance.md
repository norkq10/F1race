# 验收指南

对应《F1race 项目任务单 v0.2》的技术任务单与第十节「全局验收标准」。
当前版本：**M5**（涵盖 M1 可驾驶原型 / M2 计时与成绩 / M3 漂移 / M4 幽灵车 / M5 AI 与排名）。

---

## 一、跑起来

```bash
pnpm install
pnpm dev            # http://127.0.0.1:5180/
```

首屏会看到 `3 - 2 - 1 - GO!` 倒计时，随后与 3 台 AI 同时发车。

**操作**：`W/↑` 油门 · `S/↓` 刹车倒车 · `A D/← →` 转向 · `Space` 漂移 · `R` 重开 · `Esc/P` 暂停
**难度**：屏幕底部中间的 `简单 / 普通 / 困难` 可以在发车前切换（会重开比赛）。

---

## 二、自动验收

```bash
pnpm verify         # = typecheck + 单元测试 + 构建 + 浏览器 e2e
```

| 命令 | 作用 | 规模 |
| --- | --- | --- |
| `pnpm typecheck` | TypeScript 严格模式类型检查 | — |
| `pnpm test` | 纯逻辑单元测试（Node 内置 runner，零第三方依赖） | **155 项** |
| `pnpm build` | 生产构建 | — |
| `pnpm e2e` | Playwright 无头 Chromium 真机操作验收 | **84 项** |

e2e 里的「跑完 3 圈」「AI 跑 25 秒」「难度对比」都是真实驾驶出来的，所以一次 full verify 约需 5–6 分钟。
截图与详细报告在 `tools/screenshots/`（`report.json`）。

### 单元测试覆盖什么

总数见 README 的生成表（不要手写）。按模块：

| 文件 | 覆盖 |

| **`open-track.test.ts`** | **单程赛道（CR-16）**：跑完一趟即完赛、冲线后成绩冻结、进度钉在 100%、跨过终点不误判切弯、单程倒车，以及**闭环仍按 3 圈跑**的回归 |
| **`track-geometry.test.ts`** | **连续弧长（切弯误判的回归）**：合成 U 形赛道上"全局查询会跳段 / 连续查询不跳段"、真瞬移回落全局、单程夹两端与闭环绕回、归一化约定 |
| `drift.test.ts` | 漂移契约 D1–D9，含**与 M1 纵向模型的逐位数值回归**（`Object.is`，4 组场景 × 600 帧） |
| `ghost.test.ts` | 采样、最短弧朝向插值（±π 双向）、越界返回、手改数据校验 |
| `ghost-timebase.test.ts` | **幽灵车回放必须与录制同速**：6 种刷新率与抖动帧长下，任意时刻位置都要等于"玩家本应在的位置" |
| `save.test.ts` | v3 读写、分段独立比较、无效成绩不入纪录、**v2→v3 与 v1→v3 迁移**、ruleset 变更清纪录、损坏存档不崩 |
| `skins.test.ts` | **皮肤系统（CR-15）**：定义白名单（不许带数值）、存储键与成绩存档解耦、版本迁移、掉落权重、重复解锁、持久化降级 |

### e2e 覆盖什么

| 验收点 | 自动断言 |
| --- | --- |
| 启动 / 像素渲染 | 无 JS 与 console 报错、WebGL、canvas `image-rendering: pixelated` |
| REQ-001 操作 | `W` 加速、`D`/`A` 转向、`S` 倒车 |
| REQ-002 视角 | 主角偏离屏幕中心 < 2px |
| REQ-003 草地 | `surfaceFactor=0.600`、稳态 312px/s（赛道 520，正好 −40%）、回赛道恢复到 1.000 |
| **REQ-004 漂移** | 不按 Space 满舵 0.45s 横向速度 0.00px/s；按住 Space 峰值侧滑角 >0.18 rad；松开后侧滑归零并复位；漂移不突破极速 |
| REQ-005 / REQ-011 三圈 | 真实跑完 3 圈，总时间 = 各圈之和（<0.001ms） |
| M2 精确计时 | 帧边界累计 − 精确总时间 = 11.1ms，落在 `[0, 一帧)` |
| M2 分段 / delta / 悬停 | 每圈 3 段且之和等于圈速；实时 delta 出现且 HUD 可见；Esc 暂停期间计时零增长 |
| M2 无效圈 | 抄近道 → 3 圈全判无效、无最佳圈、不刷新最佳总时间、历史留痕 |
| **REQ-006 幽灵车** | 刷新最佳后写入约 1030 个采样点；同场半透明回放且位置随时间推进 |
| **M4 幽灵车同速（回归项）** | 与"同样跑法再跑一遍"18 秒后仍然咬在一起：玩家 7726px vs 幽灵车 7725px，**差 0px**（回放若偏快 11% 会差到约 1000px） |
| **REQ-018 幽灵车无碰撞** | 无物理体；玩家与它重叠后仍保持 471px/s 不掉速 |
| REQ-013 本地保存 | 刷新后纪录/历史/检查点曲线仍在；存档 `version: 3` |
| **存档迁移** | v1（无 ruleset）→ 纪录按规则变更清空、历史保留；v2 且 ruleset 一致 → 成绩完整保留；旧键被清理 |
| REQ-014 碰撞 | 撞墙不穿透、可倒车脱困；**玩家被 AI 追尾会被推开**（M2 时无第二台车，这条没测过） |
| REQ-015 起跑 | 倒计时期间速度为 0；结束后同时解锁 |
| **REQ-007 人机对手** | 同场 4 台车；AI 25 秒内各自推进 >9500px，不卡墙 |
| **REQ-008 人机难度** | 12 秒平均推进：简单 3696px vs 困难 5046px（**快 37%**）；且不超过各自速度上限 × 时间 |
| **REQ-016 排名** | 名次连续（1..4）、玩家名次在范围内、结算界面给出最终排名 |
| 反作弊 | 起点蹭线 4.5 秒圈数仍为 0；每圈用时 >5s |
| **CR-15 皮肤** | 6 张贴图全部预载；抽奖中奖真的解锁皮肤；车库区分拥有/未拥有并高亮新皮肤；车库打开时暂停；装备后贴图立刻变化（车库内 + 重开比赛后）；刷新页面后状态保留；重复抽奖有明确文案 |
| **CR-15 皮肤不影响成绩** | 换皮肤前后物理配置快照只有 `textureKey` 变化（body 半径/偏移/最大速度/阻力/显示尺寸全部一致）；同一套脚本输入跑固定帧数，两种皮肤下的走位与计时**逐位相同** |
| **CR-08 抽奖收口** | 发布默认 `enabled=false`、`winRate=0.35`（断言不得是 0.99）；`?lottery=test` 才把中奖率提到 99% |
| **CR-16 单程赛道** | 切到「漂移龙」后 meta 是 `open: true` / `laps: 1`；HUD 文案切成「进度 / 本趟用时」且不显示 `1/1`；跑完一趟只有 **1 条成绩**即结算；未完赛的车显示「进行中」而不是「第 N 圈」 |
| **炼狱难度（四档）** | 四档都能切换；单调性自检通过（越难的档每一项都更强）；e2e 实测 12 秒平均推进「炼狱 > 困难」 |
| **切弯判定不误伤** | 过弯冲出赛道压草地不再被判「进度异常跳跃」：单测用合成 U 形赛道钉死"全局查询会跳段、连续查询不会" |
| 性能 | 无头软件渲染下 60+ FPS |

## 三、需要人工试玩的验收项（约 5 分钟）

自动验收测不了"爽不爽"，请重点体验这几项：

1. **漂移手感（REQ-004 / REQ-012）—— 本轮最需要你拍板的部分**
   - 按住 `Space` 打方向，车尾是否甩得出去？侧滑是否看得见（HUD 左下角有「漂移 x.xx rad」指示）？
   - 松开 `Space` 后回正是否自然？
   - 目前满舵漂移时**车头转得比较快**，容易滑出赛道。如果你觉得"能漂但不好控"，
     需要调 `TUNING.vehicle.drift.driftSteerBoost`（转向倍率）和 `driftLateralPush`（侧滑推力）。
2. **和 AI 比赛（REQ-007 / REQ-008）—— 请四档都跑一圈，重点试「炼狱」**
   - 简单档是否明显好赢？困难档是否明显难缠？**炼狱档是不是"刚好咬住你"**？
   - 实测（真物理 + 真赛道，3 个 seed 平均）：环城 3 圈 —— 简单 64.4s / 普通 54.1s /
     困难 48.1s / **炼狱 46.9s**；峡谷 3 圈 —— 87.9 / 73.6 / 64.4 / **62.3s**；
     漂移龙 1 趟 —— 59.3 / 50.7 / 45.9 / **45.0s**。
   - 参考：玩家自动驾驶（`setAutopilot(true)`）环城约 52s、漂移龙约 46.8s ——
     也就是**炼狱档会压着自动驾驶的水平**。如果你觉得还不够，说明问题不在 AI 参数上，
     而是"车本身能跑多快"，那要动 `TUNING.vehicle`（会影响你自己，需要一起评估）。
   - AI 会不会挡路、会不会撞你、会不会卡在墙上？（四档在三张图上实测都是**零贴墙**）
3. **幽灵车（REQ-006）—— 需要先跑出一个最佳成绩**
   - 第一次完赛后重开，应该能看到半透明幽灵车同场跑，HUD 左上角显示与它的时间差。
   - 它是否让你有"追上去"的感觉？
4. **计时反馈与"切弯"判定（M2）**
   - 屏幕顶部的实时 delta（红/绿）是否有用？结算里的各圈成绩 / 分段 / 最近成绩是否够看？
   - **过弯失误冲出赛道压草地时，还会不会莫名其妙地被判"切弯 / 进度异常跳跃"？**
     （曾经会 —— 见 `docs/known-issues.md` 第 22 条。现在每帧计时走的是连续弧长查询。）
5. **像素风与可读性**
   - 4 台车在赛道上是否分得清（玩家红、AI 蓝/黄/绿）？HUD 信息是否过载或不够？
6. **车辆皮肤（CR-15）—— 需要先打开抽奖**
   - 用 `?lottery=test` 打开抽奖（发布默认**关闭**），刷新一次纪录就会弹老虎机。
   - 中奖后按 `G` 打开车库：6 款皮肤是否分得清、"未拥有"是否一眼看得出？
   - 点一款已拥有的皮肤，车身是否立刻变化（不用重开比赛）？刷新页面后是否还保留？
   - 重复抽到同一款时，面板上的提示是否足够明确（这是最容易被玩家记恨的地方）？

### 试玩时可直接用的调试开关

| 命令 | 作用 |
| --- | --- |
| `?debug=1` | 显示物理碰撞体与赛道中心线 |
| `?lottery=test` | 打开抽奖（发布默认关闭）并把中奖率提到 99%，用来验收皮肤产出 |
| `__F1RACE__.setAutopilot(true)` | 让玩家车自己跑 |
| `__F1RACE__.setAiEnabled(false)` | 关掉 AI 对手（想安静练车时用） |
| `__F1RACE__.setDifficulty('easy'\|'normal'\|'hard')` | 直接切难度 |
| `__F1RACE__.getState()` | 打印计时 / delta / 漂移 / 名次 / AI / 幽灵车 / 存档 / 皮肤全部状态 |
| `__F1RACE__.openGarage()` / `closeGarage()` | 开关车库（CR-15） |
| `__F1RACE__.equipSkin('gold')` | 装备皮肤（未拥有不生效，返回 false） |
| `__F1RACE__.getPlayerPhysics()` | 玩家车的贴图 + 物理配置快照（验"皮肤不碰物理"） |
| `__F1RACE__.cheatTeleport(0.5)` | 制造"抄近道"式进度跳跃，验证无效圈 |
| `__F1RACE__.clearSave()` | 清掉本地纪录，从零验收 |
